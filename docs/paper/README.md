# Paper reading guide

*Blind by construction: verifying a georeferenced map series when the check shares the error.*
[Documentation guide](../README.md).

| I want to… | Read |
|---|---|
| Read the manuscript | [Draft](draft.md) or [rendered PDF](blind-by-construction.pdf) |
| Check a claim and its evidence | [Claim audit](claim-audit.md) |
| Understand the figures | [Figure notes](figures.md) |
| Find related literature | [Related work](related-work.md) |
| Check publication preparation | [Submission](submission.md) and [Zenodo readiness](../../work/research/zenodo/README.md) |
| Read the latest recorded review decision | [Session 4 editorial decision](revision/session4-review/editorial-decision.md) |
| Edit or rebuild the manuscript | [Paper instructions](CLAUDE.md) |

`draft.md` is the hand-edited manuscript. The LaTeX, PDF and submission document are generated;
follow the paper instructions when rebuilding or changing claims. `revision/` holds review and
integrity records. Outlines, visual plans and rebuild checklists provide supporting planning context;
the manuscript and claim audit are the entry points for assessing the current argument.
