# Research sources and release materials

Source-derived data, rights evidence and prospective release packages. [Work guide](../README.md).

| Folder | What to read or inspect |
|---|---|
| [CartoMundi rights](cartomundi-rights/README.md) | Nakala rights index for Tonkin and Indochine sheets |
| [Doling](doling/SOURCE.md) | Source citation and provenance for derived place-name data |
| [Zenodo preparation](zenodo/README.md) | L7014 release checklist and package; prepared locally, no minted DOI |
| [Press](press/) | Local newspaper search artifacts |
| [Legend](legend/) | Local timeline artifacts built from newspaper research |
| [Reports](reports/) | Local generated reports |

`press/`, `legend/` and `reports/` are gitignored and may be absent in a fresh checkout.
For commands use [Pipelines](../../docs/pipelines.md); for findings use the
[journal index](../../docs/journals/README.md). Check provenance and rights before reuse.
