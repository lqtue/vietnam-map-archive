Saigon Six — Tie-Point Picker

Click the same real-world feature on two or more of the six sheets. Each click records the pixel it landed on in that sheet's own full-resolution scan — the space sheet_align.mjs already warps through each sheet's georeference. Copy the JSON out when you're done and drop it into work/analysis/saigon6/points.json.

How to use this:
  1. Type a label for the feature you're about to click (e.g. pont tournant) in the box on the right.
  2. Find that feature on the sheet showing in the viewer, and click it once — a numbered pin drops.
  3. Switch tabs to another sheet. Click the same feature there. Repeat for as many sheets as show it.
  4. Click an existing label chip to resume adding points under that same label instead of retyping it.
  5. When you've got a handful of points, hit Copy JSON and paste it over the contents of points.json (or just paste it back to me).
